# Draco decoder

Copied from `three/examples/jsm/libs/draco/` (three 0.155.0) so the playground's
Draco-compressed `scene.glb` models load without downloading the decoder from
www.gstatic.com. The demos pass `/draco/` to `useGLTF()`.
